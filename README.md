# flight-tracker
Flask app for parsing radar flight data and plotting flight paths from a one week work experience at NATS.

## Features
- Upload radar data files
- Search a flight in file by its SSR code
- Parse and extract flight information
- Display flight paths visually
- Fully documented workflow with screenshots

## Running the app
- Clone the repository:
   git clone https://github.com/alana-mch/flight-tracker.git
- Install dependencies:
   pip install -r requirements.txt
- Run the Flask app:
   python app.py
- Open your browser at:
   http://127.0.0.1:5000/
